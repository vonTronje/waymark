# README

Waymark is a shared campaign knowledge base for tabletop role-playing games.

It helps players and game masters organize people, places, factions, events, goals, and journal entries, while preserving the different perspectives and knowledge each character or player has. Information is connected through meaningful relationships, so a campaign can be explored as an evolving network of places visited, people met, events experienced, and unresolved threads.

Waymark aims to keep this information easy to capture, easy to navigate, and selectively shareable without exposing knowledge that character or player should not have.
